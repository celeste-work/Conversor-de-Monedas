# Conversor de Monedas 💱

Un programa interactivo en Java que permite convertir valores entre diferentes monedas usando la API ExchangeRate.

## Descripción 📝

El **Conversor de Monedas** es una herramienta sencilla que utiliza una API de tipo REST para obtener tasas de cambio en tiempo real. Este proyecto es ideal para aprender sobre:
- Manejo de APIs en Java.
- Uso de la librería Gson para trabajar con JSON.
- Implementación de un menú interactivo para la consola.

### Funcionalidades 🌟

- Conversión de dólares a varias monedas y viceversa:
  - Dólar a Pesos Argentinos.
  - Pesos Argentinos a Dólar.
  - Dólar a Real Brasileño.
  - Real Brasileño a Dólar.
  - Dólar a Pesos Colombianos.
  - Pesos Colombianos a Dólar.
- Llamadas a la API ExchangeRate para obtener tasas de cambio actualizadas.
- Validación de entradas del usuario para evitar errores.

## Requisitos Previos 📋

Asegúrate de tener lo siguiente antes de ejecutar el proyecto:
- [Java 17](https://www.oracle.com/java/technologies/javase-jdk17-downloads.html) o superior.
- Un IDE para Java (como IntelliJ IDEA, Eclipse o VS Code con soporte para Java).
- Conexión a Internet para usar la API.
